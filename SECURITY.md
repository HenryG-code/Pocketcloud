# Security policy

PocketCloud is a portfolio project under active development. It has no supported releases yet.

## Reporting a vulnerability

Report privately through this repository's GitHub **Security** tab, using "Report a vulnerability".
Please do not open a public issue for exploit details.

Include the affected version or commit, reproduction steps and the likely impact. Do not include
passwords, tokens or personal files. Credentials are never needed to report an issue.

## Scope

Report issues in this repository's code and configuration. Demonstration deployments use synthetic
data and may be offline at any time.
